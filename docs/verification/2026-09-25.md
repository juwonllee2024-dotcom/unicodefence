## Scope boundary

The MVP scans one explicitly selected UTF-8 file. It does not inspect a live
clipboard, browser DOM, HTML/CSS hiding, images, or semantic prompt-injection
content. `CLEAN` means only that the selected default Unicode rule set found no
finding.
